## 1. Purpose

This document specifies `content/facts.yaml` — the single source of truth for every fact cited in the family seed investment package — and the drift-check algorithm that protects facts from regressing across future versions.

This is the minimum-viable content model. Full content model with sections, fragments, and manifests (PRP-C) is deferred to next cycle.

---

## 2. Schema

Each fact in `content/facts.yaml`:

```yaml
- id: <kebab-case-slug>
  value: <the current canonical value>
  units: <USD | USD/hr | USD/yr | percent | integer | string | ISO-date>
  source: <URL or relative file path>
  effective_date: <ISO date when this value became canonical>
  review_date: <ISO date when this should be re-verified>
  confidence: <0.0–1.0>
  scope: <plan | pricing | legal | ops | all>
  notes: <optional context, 1–2 sentences>
```

## 4. Drift-check algorithm

```python
def drift_check(facts_path, lock_path, generated_html_paths):
    facts = load_yaml(facts_path)
    lock = load_yaml(lock_path)

    # Phase 1: lock vs source
    for fact in facts:
        if fact.id not in lock:
            return DriftError(f"New fact {fact.id} requires version bump", fact)
        if normalize(fact.value) != normalize(lock[fact.id].value):
            return DriftError(f"Fact {fact.id} changed without version bump", fact)

    # Phase 2: generated HTML vs source
    for html_path in generated_html_paths:
        text = read_text(html_path)
        for fact in facts:
            expected = render_fact(fact)
            if expected not in text:
                return DriftError(f"HTML {html_path} missing fact {fact.id}", fact)

    return OK
```

**Output:** Exit 0 on success; exit 1 with fact ID and file path on failure.

**Caller:** `scripts/preflight.py --check-facts`.

---

## 5. Lock file format

`output/reports/facts.lock.yaml` mirrors `content/facts.yaml` exactly. Generated by:

```bash
cp content/facts.yaml output/reports/facts.lock.yaml
```

After every successful preflight, the lock is regenerated. The lock prevents drift; the source prevents errors.
